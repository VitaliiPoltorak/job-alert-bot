# Job Alert Bot

Проверяет новые вакансии на Djinni и DOU (через их официальные RSS-фиды),
сравнивает каждую новую вакансию с твоим резюме через Claude API и шлёт
подходящие (score ≥ 65/100) в Telegram вместе с сопроводительным письмом.
Опционально каждая такая вакансия также записывается строкой в Google Sheets,
чтобы было удобно отмечать, куда уже отправлен отклик. Работает бесплатно
на GitHub Actions по расписанию (каждые 30 минут).

## Как это работает

1. GitHub Actions запускает `fetch-jobs.mjs` по cron-расписанию.
2. Скрипт читает RSS-фиды (список — в начале `fetch-jobs.mjs`, легко редактируется).
3. Новые вакансии (которых нет в `state/seen.json`) отправляются в Claude API
   вместе с текстом резюме (`resume.txt`) для оценки соответствия.
4. Если оценка ≥ порога — Claude генерирует сопроводительное письмо на языке
   вакансии, и всё это (оценка, ссылка, письмо) летит в Telegram.
5. Если настроена интеграция с Google Sheets — та же вакансия дописывается
   строкой в таблицу с пустой колонкой "Статус отклика" для ручных пометок.
6. Список увиденных вакансий коммитится обратно в репозиторий, чтобы не дублировать
   уведомления при следующем запуске.

## Шаг 1. Создать Telegram-бота и узнать chat_id

1. В Telegram открой **@BotFather** → `/newbot` → следуй инструкциям → получишь `TELEGRAM_BOT_TOKEN`.
2. Напиши своему новому боту любое сообщение (просто "привет"), чтобы у него появился с тобой чат.
3. Открой в браузере:
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   Найди в ответе `"chat":{"id":123456789,...}` — это твой `TELEGRAM_CHAT_ID`.

## Шаг 2. Получить Anthropic API key

1. Зайди на console.anthropic.com → раздел API Keys → создай ключ.
2. Это платный API (отдельно от твоей подписки Claude.ai), но при таком объёме
   запросов (несколько вакансий раз в 30 минут) расходы обычно центы в день.

## Шаг 3 (опционально). Настроить запись в Google Sheets

Если хочешь удобно отмечать, куда уже отправлен отклик, — заведи Google-таблицу
и подключи её через сервис-аккаунт (авторизация без интерактивного логина,
подходит для GitHub Actions):

1. Зайди на [console.cloud.google.com](https://console.cloud.google.com) →
   создай новый проект (или выбери существующий).
2. В разделе **APIs & Services → Library** найди **Google Sheets API** → **Enable**.
3. В разделе **APIs & Services → Credentials** → **Create Credentials** →
   **Service Account** → задай любое имя → **Create and Continue** → **Done**.
4. Открой созданный service account → вкладка **Keys** → **Add Key** →
   **Create new key** → тип **JSON** → скачается файл ключа.
5. В скачанном JSON найди поля:
   - `client_email` — это будет `GOOGLE_SERVICE_ACCOUNT_EMAIL`;
   - `private_key` — это будет `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` (копируй
     значение целиком, включая `-----BEGIN PRIVATE KEY-----` и `-----END PRIVATE KEY-----`).
6. Создай новую Google-таблицу (sheets.google.com) для вакансий.
7. Нажми **Share** в таблице → добавь email из `client_email` (шаг 5) с правом
   **Editor**. Без этого сервис-аккаунт не сможет писать в таблицу.
8. Скопируй `GOOGLE_SHEET_ID` — это часть URL таблицы между `/d/` и `/edit`:
   `https://docs.google.com/spreadsheets/d/`**`ЭТА_ЧАСТЬ`**`/edit`.

Заголовок таблицы (Дата / Оценка / Вакансия / Ссылка / Причина / Сопроводительное
письмо / Статус отклика) скрипт создаёт сам при первом запуске, если строка
1 пустая. Если хочешь писать не в первый лист таблицы — добавь секрет
`GOOGLE_SHEET_NAME` с точным названием вкладки (по умолчанию `Sheet1`).

Если эти секреты не заданы — бот просто не пишет в таблицу, ничего не ломается.

## Шаг 4. Выложить проект на GitHub

```bash
cd job-alert-bot
git init
git add .
git commit -m "Initial commit"
gh repo create job-alert-bot --private --source=. --push
# либо вручную: создай приватный репозиторий на github.com и запушь эту папку
```

Важно: сделай репозиторий **приватным** — там лежит твоё резюме.

## Шаг 5. Добавить секреты в репозиторий

В репозитории: Settings → Secrets and variables → Actions → New repository secret.
Обязательные секреты:
- `ANTHROPIC_API_KEY`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Опциональные (если настроил Google Sheets на шаге 3):
- `GOOGLE_SERVICE_ACCOUNT_EMAIL`
- `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY`
- `GOOGLE_SHEET_ID`
- `GOOGLE_SHEET_NAME` (если вкладка называется не `Sheet1`)

## Шаг 6. Запустить

Actions уже настроены на автозапуск каждые 30 минут. Чтобы проверить сразу,
не дожидаясь расписания: вкладка **Actions** → **Check new jobs** → **Run workflow**.

## Настройка под себя

- **Список источников** — массив `FEEDS` в начале `fetch-jobs.mjs`. Можно добавить
  другие ключевые слова Djinni (`?primary_keyword=...`) или категории DOU
  (`?category=...`), просто зайдя на сайт, настроив фильтр и скопировав
  `.../feeds/?...` (Djinni) или найдя ссылку `RSS` на странице (DOU).
- **Порог совпадения** — константа `MATCH_THRESHOLD` (0-100).
- **Резюме** — просто отредактируй `resume.txt`, ничего в коде менять не нужно.
- **Частота проверки** — строка `cron` в `.github/workflows/check-jobs.yml`.
  Не ставь слишком часто (например, раз в минуту) — увеличивает нагрузку и
  расход API без особой пользы, вакансии не появляются так быстро.

## Про LinkedIn

Специально не стал добавлять сюда LinkedIn: у него нет публичного RSS для
поиска вакансий, а автоматический доступ к сайту (логин, скрапинг) прямо
запрещён их правилами использования и технически заблокирован (капча).
Вместо этого рекомендую:
1. На linkedin.com/jobs настроить обычный фильтр поиска → включить "Job Alerts"
   (кнопка над списком результатов) → LinkedIn сам будет слать email при новых
   вакансиях по этому фильтру.
2. При желании эти письма можно тоже читать автоматически (через IMAP) и
   прогонять через тот же скоринг — скажи, если такое нужно, соберу отдельно.

## Про DOU

DOU отдаёт вакансии через официальный RSS (`jobs.dou.ua/vacancies/feeds/?category=...`),
поэтому в отличие от Djinni там даже не нужно подбирать специальный формат
ссылки — просто ищи кнопку "RSS" на странице с нужными фильтрами.
